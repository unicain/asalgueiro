# PLANILHA DE CONTEÚDOS — ANDRÉA SALGUEIRO
### Numerologia Terapêutica & Terapias Energéticas

Esta planilha foi organizada para que a **Andréa Salgueiro** possa ler, revisar e alterar qualquer texto, título, descrição de serviço ou pergunta do site com facilidade.

---

## 📥 Como abrir no Google Planilhas (Google Sheets)

1. Baixe o arquivo **`conteudos-site-andrea-salgueiro.csv`** (disponível na pasta `/public` ou pelo link do site `/conteudos-site-andrea-salgueiro.csv`).
2. Abra o [Google Drive](https://drive.google.com).
3. Clique em **Novo > Fazer upload de arquivo** e selecione o arquivo `.csv`.
4. Abra o arquivo carregado e clique em **Abrir com > Planilhas Google**.
5. Compartilhe com a Andréa com permissão de edição.

---

## 🗂️ Estrutura das Colunas da Planilha

| Coluna | Nome | Descrição |
|---|---|---|
| **A** | `ID` | Código identificador único de cada campo (ex: `HERO-02`, `SRV-01D`). **Não alterar**. |
| **B** | `Seção` | Onde esse texto aparece no site (Hero, Sobre, Serviços, Depoimentos, FAQ, etc.). |
| **C** | `Elemento / Campo` | Nome do campo (ex: Título Principal, Subtítulo, Benefício 1). |
| **D** | `Conteúdo Atual (Site)` | O texto que está no ar hoje para a Andréa ler e validar. |
| **E** | `Instruções para Andréa` | Dica sobre o tamanho ideal do texto ou função daquele trecho. |
| **F** | `Novo Conteúdo (Andréa)` | **Espaço para a Andréa digitar a versão aprovada ou alterada**. |

---

## 🔄 Como sincronizar os textos atualizados de volta para o site

Quando a Andréa terminar de preencher:

1. No Google Planilhas, clique em **Arquivo > Compartilhar > Publicar na Web**.
2. Escolha o formato **Valores separados por vírgula (.csv)** e clique em **Publicar**.
3. Copie o link gerado (começa com `https://docs.google.com/spreadsheets/d/e/.../pub?output=csv`).
4. Envie o link ou me avise aqui no chat! Com esse link, o site pode ler os dados diretamente ou eu aplico todas as edições da Andréa de uma só vez de forma 100% automatizada.
